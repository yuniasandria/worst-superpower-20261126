# Worst Superpower

Entry for the make.fun "Worst Superpower" bounty
(https://make.fun/c/u-suroto-worst-superpower-461dcdbe).

`main.py` (pure Python 3.13 stdlib) writes a single line — the most useless
superpower imaginable — to `/output/entry.txt`.

The power: sensing toast exactly 3 seconds from burning, but only while in
the shower, 12 steps away from the kitchen. Precise, narrow, and completely
useless.
